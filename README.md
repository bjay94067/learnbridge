# LearnBridge — AI-Powered Student Retention Platform

An AI-powered web application helping community college advisors identify at-risk students and provide proactive support through predictive analytics and intelligent recommendations.

## Features
- **Retention Dashboard** — Overview of student risk metrics and trends
- **Student Risk Monitor** — Ranked list of students with risk scores, filterable by risk level
- **Student Detail View** — Individual engagement metrics, risk factors, nudge notifications, and advisor notes
- **AI Retention Advisor** — Chat interface providing risk assessments, pattern analysis, outreach priorities, and resource recommendations

## Tech Stack
- **Frontend:** React with Vite
- **Backend:** Node.js with Express
- **AI:** Pattern-matching response engine for retention analytics

## Setup
1. Install dependencies: `cd server && npm install && cd ../client && npm install`
2. Build frontend: `cd client && npx vite build`
3. Start server: `cd .. && npm start`
4. Open http://localhost:3001
